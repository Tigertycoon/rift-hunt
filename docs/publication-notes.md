# Publication notes

Rift Hunt is the implemented exploration-game part of the local StoryMint AR project. Other ideas from planning material, including a Hidden Alien mode, are not presented as implemented features here.

The repository preserves the authored gameplay, shaders, browser bridges, tracking integration source, trail data and target photographs. It excludes proprietary SDK implementations and demos, purchased VFX packs, deployment folders, old builds, local tool configuration, screenshots and caches. The original working folder is unchanged.

Publication maintenance:

- Proprietary integrations are behind explicit scripting symbols; the default project imports without them.
- A manual provider and a small editor preview exercise the existing gameplay code without asserting real tracking.
- The default trail is `rift-hunt-preview.json`; historical trails are preserved separately.
- The vendor example flower target was replaced with an included authored outdoor target reference.
- Links to external production games were replaced with the included completion-handoff test page. Those external games are not part of this repository.
- Company/project metadata and the default WebGL template were neutralized for the standalone publication.
- Trail, browser and Unity checks document their precise scope.

The preview is a verification entry point, not a new visual showcase. The project retains prototype limitations and does not claim a completed production AR release.
